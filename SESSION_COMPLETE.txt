🏗️  ARCHITECTURE TRANSFORMATION
═══════════════════════════════════════════════════════════════════════════════

BEFORE (Legacy Internal):
  UMO stores: { name, id, puid, team }
  Export converts to: TODS Participant
  Problem: Conversion overhead on every export

AFTER (TODS Native):
  UMO stores: TODS Participant (native)
  Export returns: Same objects (zero conversion)
  Benefit: No overhead, direct access!

KEY CHANGE:
  - Replaced metadata = {} with TODSMetadata instance
  - All accessors now use TODS getters/setters
  - Internal TODS = External TODS
